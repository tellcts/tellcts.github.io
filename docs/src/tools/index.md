# 开源工具 {#open-source-tools}

这里记录我日常在用的开源工具，收录标准比较简单：能真正替掉我原有的工作流，而不只是尝个鲜。

和笔记那边边学边记的形态不同，这里偏「怎么用起来」——装完怎么敲、怎么配、哪些坑我已经替你踩过，尽量写成照着做就能跑通的样子。

## 🧰 工具列表 {#tool-list}

- 🐍 [**Python构建工具UV**](/tools/uv/)：用 Rust 写的 Python 包与项目管理器，一个二进制替掉`pip`、`virtualenv`、`pipx`、`poetry`；同章节还收了 Astral 的 Ruff，负责代码检查与格式化。
