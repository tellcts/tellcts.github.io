# Python构建工具UV

Astral 用 Rust 写的 Python 包与项目管理器，把`pip`、`virtualenv`、`pipx`、`poetry`收敛成一条命令。

## 📚 章节内容

- 🧭 [**UV简介与安装**](/tools/uv/intro)：它是什么、相比`pip`与传统工具链的优势，以及各平台的安装、升级与卸载方式。
- ⌨️ [**常用命令与配置**](/tools/uv/commands)：Python 版本管理、项目管理、Shell 自动补全与镜像加速配置。
- 🧹 [**代码检查与格式化工具Ruff**](/tools/uv/ruff)：Astral 主导开发的极速 Python 代码检查、格式化工具。
