# 信息安全工程师

这里是我整理软考「信息安全工程师」的知识笔记，按知识模块铺开，边学边记。

写法和「开源工具推荐」那种照着敲的教程不同，这里更看重把原理讲清楚：概念、机制、以及为什么这么设计，顺带记下我自己理解偏了又掰回来的地方。

## 📚 章节内容

- 📖 [**安全基础知识**](/notes/info-sec/basic)：共十四章，从网络信息安全概述、网络攻击原理、密码学与网络安全体系，一路讲到认证、访问控制、防火墙、VPN、入侵检测、物理隔离、安全审计、漏洞防护与恶意代码防范，以理论知识点为主。
- 🧪 [**案例知识总结**](/notes/info-sec/advanced)：偏实战，目前有 iptables 防火墙的配置案例（四表五链、常见规则写法）与 Wireshark 过滤器语法（捕获过滤器与显示过滤器）。
